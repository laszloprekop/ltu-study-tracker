# Graded answers stay inside the Group

Cards exist to build correct knowledge fast, but a written answer to a graded question (a lab
reflection, a report question) shared across the class would let several Groups hand in the same
text, which LTU treats as cheating and which plagiarism checks find. So shared Cards are Concept
Cards and Question Cards: the question word for word, pointing to the Concept Cards and material that
answer it, never a written answer. Answer Cards are visible only to the Group that wrote them, where
working out the answer together is allowed, or only to one Student.

## Consequences

The database enforces this (see ADR 0003); no setting or Maintainer action makes an Answer Card
public. Revisit only with the courses' written rules on collaboration in hand.
